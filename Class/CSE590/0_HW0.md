# Mounting a Filesystem

| Commands                                  | Description                          |
| ----------------------------------------- | ------------------------------------ |
| `sudo sgdisk -n 1:2MiB:12MiB /dev/sdb`    | Partition the device                 |
| `sudo fdisk -l /dev/sdb`                  | Verify the partition was created     |
| `yes \| sudo mkfs -t ext4 /dev/sdb1`      | Format the partition                 |
| `sudo mkdir -p /mnt/test1`                | Make mounting point                  |
| `sudo mount -t ext4 /dev/vdb1 /mnt/test1` | Mount the filesystem onto /mnt/test1 |

# Raid Levels

| Raid Level | Description                 | Pros                                 | Cons                                                |
| ---------- | --------------------------- | ------------------------------------ | --------------------------------------------------- |
| RAID 0     | Striping                    | High performance, full disk capacity | No redundancy                                       |
| RAID 1     | Mirroring                   | Redundancy, data protection          | 50% disk capacity usage                             |
| RAID 5     | Striping with parity        | Redundancy, efficient storage        | Requires at least 3 disks, slower write performance |
| RAID 6     | Striping with double parity | Higher redundancy                    | Requires at least 4 disks, slower write performance |
| RAID 10    | Striping and mirroring      | High performance, redundancy         | Requires at least 4 disks, 50% disk capacity usage  |
