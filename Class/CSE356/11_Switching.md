# LAN

- All nodes in the network share the channel
- Everyone can hear everyone else
- Nodes within LAN uses MAC as the address

# Ethernet Broadcast

- Each NIC compare its MAC address
	- If match, copy rest of the frame
	- else, ignore rest of frame

# How is data sent in LAN?

Packets are broadcasted to the network to the correct destination MAC address
